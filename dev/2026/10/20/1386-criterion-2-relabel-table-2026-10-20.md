**Read this first: what the harness measures.** `determine_actual_routing` (`canonical-retest-1386-alpha.py:550-560`) returns `floor` if `floor_hit`, `action` if category == execution, and otherwise `canonical`. So a rail dispatch whose classifier category is QUERY/ANALYSIS/SYNTHESIS reads as `canonical` even when the rail entry is a WRITE. "action" here means "EXECUTION category, not floor", which includes the #1333 honest-decline branch. That affects Q40 below.

Strength: **ruling** = a dated ruling about this kind of query (corpus row note, decisions.log or code comment). **corpus** = an inversion-corpus row asserting this destination for a near-verbatim phrase, with no dated ruling. **registration** = the action is only registered on a rail. **none** = no basis found.
